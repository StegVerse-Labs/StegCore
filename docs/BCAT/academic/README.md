# BCAT Academic Research Track

This directory contains materials for the **academic formalization and publication**
of concepts originating in the StegCore doctrine on **Boundary-Conditioned Autonomy and Trust (BCAT)**.

## Relationship to StegCore Doctrine

StegCore is the **canonical source of truth** for BCAT.

- All academic publications **derive from**, but do not define, BCAT doctrine.
- No academic paper supersedes StegCore governance principles.
- Doctrine is written for humans, operators, and system designers.
- Academic artifacts translate doctrine into formal research language.

This separation is intentional.

StegCore defines *how autonomy is governed*.
Academic work explains *why this governance matters* and *how it can be reasoned about formally*.

## Scope of Academic Work

Academic publications under this directory may:
- Formalize concepts defined in StegCore doctrine
- Introduce analytical models, taxonomies, or definitions
- Propose detection signals or system properties
- Map BCAT principles to real-world systems (e.g., AI agents, CI/CD, autonomous machinery)

Academic publications must **not**:
- Introduce exploit code
- Disclose sensitive systems or credentials
- Override ethical or governance constraints defined in StegCore
- Reframe BCAT in ways that remove human accountability or sovereignty

## Intended Audience

This research track is intended for:
- Computer science researchers (systems, security, AI)
- Autonomous systems and robotics researchers
- AI governance and trustworthy systems communities
- Industry research groups evaluating autonomy at scale

## Citation and Attribution

All academic publications must cite StegCore BCAT doctrine as the originating framework.

See `citation_policy.md` for required terminology and citation format.

## Design Philosophy

BCAT research prioritizes:
- Conceptual clarity over novelty claims
- Explainability over optimization
- Legitimacy of action over raw capability
- Human trust as a system property, not a sentiment

This directory exists to ensure academic rigor **without diluting the doctrine**.

# Manifested Transaction Continuity

The canonical transaction path is SDK manifestation -> ingestion -> StegGate -> return ingestion -> SDK output -> replay/reconstruction. The manifest is not authority.

The public longitudinal example is neutral and uses no personal evaluator identity: T0 is the original $420 state; T1-A keeps the $420 candidate while a current-state condition changes; T1-B changes the candidate to $4,200 while retaining the earlier $420 approval binding.

Public fixtures, workflow names, subjects, receipt metadata, PR descriptions, handoffs, examples, and inspection records must use neutral role identifiers unless an individual has explicitly agreed to public attribution. Personal identity is not required for submission, replay, reconstruction, or custody resolution.
